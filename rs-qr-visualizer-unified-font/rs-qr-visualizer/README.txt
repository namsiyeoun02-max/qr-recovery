제공한 사이트의 브라우저용 코드입니다. 글꼴을 굵은 고딕 계열로 통일했습니다.
원본의 구성·배치·계산 기능은 유지했습니다. 호스팅 전용 삽입 스크립트는 제거했습니다.

실행 방법
1. ZIP 압축을 풉니다.
2. index.html이 있는 rs-qr-visualizer 폴더를 VSCode에서 엽니다.
3. 터미널에 python -m http.server 8000 을 입력합니다.
   안 되면 py -m http.server 8000 을 사용합니다.
4. 브라우저에서 http://localhost:8000 을 엽니다.
종료: 터미널에서 Ctrl+C

사진만으로 정확한 폰트명은 확인할 수 없어 고딕 계열 글꼴을 700 두께로 통일했습니다.
서버 코드와 원래 배포 계정 정보는 포함하지 않습니다.
